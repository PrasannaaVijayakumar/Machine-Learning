# Machine Learning Lab Activities

This repository contains the **Machine Learning laboratory exercises and implementations** for **23CSE301 – Machine Learning**.

The implementations are developed using **Python and Google Colab**, following the experiments and exercises provided as part of the course.

## 📂 Repository Contents

### 1. Linear Regression

Implementation of Linear Regression using Python.

**Dataset:**

* Salary vs Years of Experience

**Tasks covered:**

* Importing required libraries
* Reading the dataset
* Exploring the dataset
* Checking dataset shape
* Checking null values
* Selecting independent and dependent variables
* Splitting data into training and testing sets
* Training a Linear Regression model
* Predicting values
* Visualizing the regression line

### 2. Logistic Regression

Implementation of Logistic Regression for binary classification.

**Dataset:**

* Diabetes dataset

**Features used:**

* Pregnancies
* Insulin
* BMI
* Age
* Glucose
* Blood Pressure
* Diabetes Pedigree Function

**Target:**

* `label`

**Tasks covered:**

* Reading and exploring the dataset
* Checking null values
* Selecting features and target
* Splitting the dataset
* Training a Logistic Regression model
* Making predictions
* Calculating accuracy
* Generating a confusion matrix
* Visualizing the confusion matrix using a heatmap

## 🚀 Running the Programs

The experiments can be executed directly in **Google Colab**.

### Steps

1. Open [Google Colab](https://colab.research.google.com/).
2. Create a new notebook.
3. Upload the required `.csv` dataset.
4. Copy the corresponding Python implementation into the notebook.
5. Run the cells sequentially.
6. Verify the generated outputs, predictions, metrics, and visualizations.
